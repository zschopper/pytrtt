# Terminology

- Name translation content categories **Interface** / **Felhasználói felület** and
  **Subtitles** / **Feliratok** in English / Hungarian user-facing text and documentation.
  Interface includes menus, settings, HUD, prompts, and other UI text. Subtitles include both cinematic and
  in-game dialogue captions, not just video text. Use “menu” only for a specific navigation menu, not the whole category.
  Preserve existing schema keys, identifiers, paths, and historical source quotations, including `menu` and `subtitles`.
- Reuse verified project translations and existing glossaries; treat reference translations as evidence with provenance.
- Distinguish proper nouns from descriptions using context. Do not automatically translate character/place names.
- Keep UI terms, mechanics, items, and character names consistent within the game and language.
- Record new terminology decisions in the project's existing glossary or translation comments;
  do not create a competing project plan or change terminology silently.
- Flag conflicts and ambiguity with source/entry references. Keep internal keys, variables, and placeholders unchanged.
