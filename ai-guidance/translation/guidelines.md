# Translation Guidelines

- Preserve meaning, intent, tone, speaker identity, and gameplay context; prefer natural target-language phrasing.
- Use consistent register, character voice, and established terminology; consult `terminology.md` for names and terms.
- Preserve identifiers, placeholders, markup, formatting tokens, control sequences, and required whitespace.
- Do not invent context. Record ambiguous strings with resource/entry references for review.
- Edit translation fields only unless source/metadata repair is part of the task. Preserve comments and source text.
- Keep correct Unicode in JSON. Before writing game resources, load `../file-formats/text-encoding.md`;
  do not shorten translations merely to match the original character count.
